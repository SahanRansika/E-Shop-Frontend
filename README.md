# 🛒 E-Shop Frontend

A modern e-commerce frontend built using **React + TypeScript + Vite**. This project provides a seamless shopping experience with a high-performance UI.

---

## 🌐 Live Demo
The project is officially deployed and can be accessed via the link below:

🚀 **Live Link:** [https://e-shop-frontend-1ykuthz33-sahan-ransikas-projects.vercel.app](https://e-shop-frontend-1ykuthz33-sahan-ransikas-projects.vercel.app)

---

## 🚀 Tech Stack

* **Framework:** ⚛️ React 18
* **Language:** 🧠 TypeScript
* **Build Tool:** ⚡ Vite
* **Styling:** 🎨 Tailwind CSS
* **Data Fetching:** 🔄 Axios
* **State Management:** 🗂 Zustand
* **Routing:** 🌐 React Router DOM
* **Deployment:** ☁️ Vercel

---

## 📦 Features

* **Authentication:** Secure User login and signup.
* **Product Discovery:** Listing, searching, and filtering products.
* **Shopping Experience:** Integrated Add to Cart and Checkout flow.
* **Management:** Order summary and status tracking.
* **UI/UX:** Fully responsive design with Toast notifications for actions.
* **Payments:** Integrated **PayHere (Sandbox)** for testing transactions.
